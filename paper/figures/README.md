# HMBR architecture

[`overview.png`](overview.png) reproduces the architecture diagram in Figure 2 of the [HMBR manuscript](../ReCoMER.pdf), on page 4. The diagram shows how NCHA and FCCR control the history update, SABER weights the updated modality representations, and cRBEF combines the contextual prediction with evidence from a separate audiovisual expert.
